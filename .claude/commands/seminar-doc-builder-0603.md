# セミナー運営資料ジェネレーター

ユーザーが指定したテーマで、以下の2つのHTMLファイルを生成してください。

## 入力

`$ARGUMENTS` にテーマの説明が渡されます。テーマが指定されていない場合はユーザーに確認してください。

出力ファイル名は常に固定です：
- `kikakusho.html`（社内向け企画書）
- `annai.html`（参加者向け案内ページ）

---

## 共通デザイン仕様（テーマが変わっても必ず踏襲する）

### カラーパレット
| 変数名 | 値 | 用途 |
|---|---|---|
| `--navy` | `#16365C` | ヘッダー背景・テキスト強調 |
| `--gold` | `#F4A300` | アクセント・バッジ・ボタン |
| `--bg` | `#FBF8F1` | ページ背景（生成り色） |
| `--white` | `#FFFFFF` | カード背景 |
| `--text` | `#2D2D2D` | 本文テキスト |
| `--muted` | `#5A6370` | 補足テキスト |
| `--shadow` | `0 4px 16px rgba(22,54,92,.10)` | カード影 |

### 共通レイアウトルール
- カード：`border-radius: 16px`、`box-shadow: var(--shadow)`、背景 `#FFFFFF`
- 各セクション見出しの左に「連番の丸バッジ」を置く
  - 山吹色（`#F4A300`）の円（36×36px）に白文字の数字
  - `.badge` クラスで実装
- 本文フォント：`"Hiragino Kaku Gothic ProN", "Hiragino Sans", "Noto Sans JP", "Meiryo", sans-serif`
- `line-height: 1.7`、`font-size: 15px`
- CSSは `<style>` 内にすべて内包。外部CSS・外部JS・CDN・画像URLは一切使わない
- ダブルクリックでそのままブラウザ表示できる完結した1枚のHTML

### フッター（両ファイル共通・必須）
```html
<footer>
  Produced with Claude Code ✦ 主催：<span>【テーマに合った架空の主催者名】</span>
</footer>
```
フッター背景は `var(--navy)`、テキストは `rgba(255,255,255,.45)`、`<span>` 部分は `var(--gold)` 色。

## kikakusho.html の構成（社内向け企画書）

以下の7ブロックを**必ずこの順序**で作成してください。

### ヘッダー
- 背景：`var(--navy)`
- 上部に枠線付きラベル「社内企画書 ／ INTERNAL USE」（金色枠・金色文字・角丸ピル）
- セミナータイトル（白・大文字）
- 1行キャッチコピー（山吹色・16px）

### ブロック1：開催概要
バッジ番号 **1**。以下の項目を2列テーブルで表示。
左列（ラベル列）は紺色・太字・左に山吹色の縦線（4px幅）。
右列（値列）はテーマに合った自然なサンプル値を設定。

| ラベル | サンプル例 |
|---|---|
| 開催日時 | 開催日（土日）・時間・受付開始時刻 |
| 開催形式 | Zoom ウェビナー等 |
| 定員 | 先着 XX 名 |
| 参加費 | X,XXX 円（カンマ区切り＋「円」） |
| 対象 | テーマに合う初心者像 |
| 申込締切 | 開催1週間前 |

### ブロック2：背景・なぜ今やるのか
バッジ番号 **2**。2〜3文の説明文。統計・トレンド・ニーズを盛り込む。

### ブロック3：受講後のゴール（BEFORE → AFTER）
バッジ番号 **3**。**必ず左右2カラム＋中央矢印（→）**で表現。

- BEFORE ボックス：背景 `#EEF2F7`・ボーダー `#C7D4E2`・ラベル灰色
  - 各項目の先頭に `✗`（灰色）
- AFTER ボックス：背景 `#FFF8E8`・ボーダー `#F4A300`・ラベル山吹色
  - 各項目の先頭に `✓`（山吹色）
- 中央の矢印：`→`・32px・山吹色

### ブロック4：プログラム
バッジ番号 **4**。3列テーブル（時刻／内容／所要時間）。

- ヘッダー行：`var(--navy)` 背景・白テキスト
- 奇数行：背景 `#F7F4EE`
- 時刻列：紺・太字・nowrap
- 所要時間列：灰色・小文字
- 休憩行はイタリック＋灰色（`.break-row` クラス）

### ブロック5：こんな方におすすめ
バッジ番号 **5**。山吹丸バッジ（✓マーク）付きで3項目。
`.checklist` リストで実装。

### ブロック6：持ち物・注意事項
バッジ番号 **6**。2カラムグリッドで「持ち物（任意）」と「注意事項」を並べる。
各ブロックの小見出しは山吹色の下線ボーダー付き。

### ブロック7：備考・今後の展開
バッジ番号 **7**。2〜3文で将来展開を記述。

## annai.html の構成（参加者向け案内ページ）

### ヒーローセクション
- 背景：`linear-gradient(135deg, var(--navy) 0%, #1E4A7A 50%, var(--gold) 100%)`
- `radial-gradient` の光彩エフェクトを `::before` で重ねる
- 内容（上から順に）：
  1. 枠線ラベル「ONLINE SEMINAR ／ 初心者大歓迎」
  2. セミナータイトル（白・大・`clamp`でレスポンシブ）
  3. サブタイトル（白70%・17px）
  4. 開催情報バッジ群（山吹の点 + 白テキスト）：日時・形式・定員・参加費
  5. 申込ボタン（`.btn`：山吹背景・紺文字・角丸50px・影付き・ホバーでリフト）
  6. 申込締切の注記（白50%・12px）

### 3つのポイント（横並び3カード）
- `.section` ラップ：`max-width: 900px`・中央揃え
- セクションラベル「HIGHLIGHTS」（山吹・11px・letter-spacing）
- セクションタイトル（紺・大）
- `.points-grid`：`display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px`
- 各カードの仕様：
  - 白背景・`border-top: 4px solid var(--gold)`・`border-radius: 16px`
  - 上部に POINT 番号（山吹・小文字・absolute配置）
  - 絵文字（40px・中央）
  - 見出し（紺・16px・太字）
  - 説明文（灰色・13.5px）
  - テーマに合った絵文字と内容を3点設定すること

### セパレーター
```html
<div style="height:1px; background:linear-gradient(to right, transparent, #D9D3C5, transparent); max-width:600px; margin:0 auto;"></div>
```

### FAQ（3問）
- セクションラベル「FAQ」・セクションタイトル（紺）
- 各 Q&A は白カード・`border-radius: 16px`・影付き
- Q行：山吹丸バッジ（30px）＋質問文（紺・太字）
- セパレーター（薄いボーダー）
- A行：「A.」ラベル（紺・太字）＋回答文（灰色）
- テーマに沿った自然なQ&Aを3問設定すること

### 申込みCTA
- 背景：`var(--navy)`
- 大見出し（白）：山吹色でキーワードを `<em>` 強調
- リード文（白70%）
- 開催情報バッジ群（白半透明背景・白ボーダー・白テキスト）
- 申込ボタン（`.btn.btn-large`：font-size 19px・padding 20×64px）
- 注記（白50%）

---

## 実装手順

1. `$ARGUMENTS` のテーマを解析し、開催日・定員・参加費・主催者名などのサンプル値を設定する
2. `kikakusho.html` を上記仕様に従い生成・保存
3. `annai.html` を上記仕様に従い生成・保存
4. 両ファイルを `git add` してコミット（メッセージ例：`Add seminar docs: [テーマ名]`）
5. 現在のブランチに `git push -u origin <branch>` でプッシュ

## 出力ルール

- 金額は必ず「X,XXX円」形式（カンマ区切り＋「円」）
- 日時はテーマに合った近未来の土日を選ぶ
- 外部リソース（CDN、画像URL、外部CSS/JS）は一切使わない
- すべてのサンプル値はテーマに沿って自然に設定してよい
